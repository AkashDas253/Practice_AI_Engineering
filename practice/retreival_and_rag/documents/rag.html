Retrieval-Augmented Generation

Retrieval-Augmented Generation, or RAG, combines information retrieval with language generation.

How RAG Works

A RAG system searches a collection of documents and retrieves information relevant to a user's query.

  1. Load documents
  2. Split documents into chunks
  3. Create embeddings
  4. Retrieve relevant chunks
  5. Provide retrieved context to the model
  6. Generate an answer

Retrieval

Retrieval helps an AI application access information from documents without sending the entire document collection to the language model.

Context

Retrieved information is provided to the language model as context so that the generated answer can be grounded in the available information.
